# PowerBI_Amazon_Sales_Data_Analysis

Project Overview
This project presents an interactive Power BI dashboard that analyzes Amazon sales data. The dashboard enables users to explore sales across different time periods (Year, Quarter, Month) and categories. It also focuses on Year-to-date reviews.


Tools & Technologies-:

Power BI
DAX
Excel / CSV
Data Visualization & Analytics


Dataset-:

Source: Amazon Sales data
Format: CSV
Time Period: 2019
